## 💡 Frequently Missed Details

**Windowed vs fullscreen**

ESP drawing works most reliably in **borderless windowed** mode. Exclusive
fullscreen can block the overlay on some GPU drivers.

**Multiple monitors**

If the menu appears on the wrong screen, set your primary display in Windows
before launching the loader.

**Antivirus behaviour**

Windows Defender re-scans new executables on first run. If the file vanishes
right after download, check quarantine — this is the most common "the file is
missing" report.

**Game updates**

After a game patch, the old build will not attach. Download the current
version; do not try to force the old one.

**Account choice**

simply how these tools work in practice.
